# Q-Dev Solutions

Q-Dev Solutions is a modern, responsive web application built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/). It serves as a digital portfolio and service showcase for a software development agency specializing in web development, mobile apps, and AI integrations.

## Features

-   **Modern UI/UX**: A sleek, dark-themed design with smooth animations and responsive layouts.
-   **Service Showcase**: Detailed information about services including Mobile App Development, Website Development, Software Development, UX/UI Design, AI Integrations, and QA Testing.
-   **Interactive Elements**: Custom modals for service details and interactive navigation.
-   **Contact Form**: Integrated contact form for potential clients to reach out.
-   **Legal Pages**: Dedicated Privacy Policy and Terms of Service pages.
-   **SEO Optimized**: Built with Next.js for optimal performance and search engine visibility.

## Tech Stack

-   **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Language**: JavaScript / React
-   **Icons**: Heroicons (via SVG)
-   **Fonts**: Inter and Syne (via Google Fonts)

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

-   Node.js (v18 or higher recommended)
-   npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/q-dev-solutions.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd q-dev-solutions
    ```
3.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```

### Running the Development Server

Start the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

-   `app/`: Contains the application routes, layouts, and pages (App Router).
-   `components/`: Reusable UI components (Navbar, Footer, Hero, Services, etc.).
-   `public/`: Static assets like images and icons.
-   `styles/`: Global styles and Tailwind configuration.
